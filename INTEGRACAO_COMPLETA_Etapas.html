📥 Etapa 1: Importação de Dados

Importe dados do Google Forms para a planilha. Os dados serão validados antes de prosseguir.

✅ Etapa 2: Validação de Dados

Valide se todos os dados foram importados corretamente. Corrija qualquer erro antes de prosseguir.

💾 Etapa 3: Salvamento na Planilha

Salve os dados validados na planilha do Google Sheets. Isso criará registros permanentes.

⚙️ Etapa 4: Processamento e Geração de Documentos

Gere contratos, declarações e outros documentos a partir dos dados salvos.

🔄 Etapa 5: Sincronização com GitHub

Sincronize os dados com o repositório GitHub para controle de versão e backup.
